## Featured projects

### KRAM — School Operations Platform

**In production · Private source code** · [Product login](https://comedor.colegiosonverinou.com)

A school-management application I built from the ground up, used in the daily operation of a real educational centre. It simplifies school meal services, attendance and extracurricular activities.

- Designed workflows for teachers, monitors, administrators and kitchen staff, with **role-based access**.
- Implemented **attendance tracking, offline-first functionality and cloud synchronisation**.
- Built administrative reporting, dietary/allergy information handling and integration with the school's existing management workflows.
- Developed as a **Progressive Web App (PWA)** for use across devices.

**Stack:** React · JavaScript · Firebase / Firestore · Cloud Functions · PWA

### 1&1 Padel — Privacy-Focused Tournament Matchmaking

**Web pilot · Internal iOS testing · Private source code** · [Explore the platform](https://www.1and1padel.com)

A platform helping competitive padel players find a partner for a specific tournament without exposing their personal information prematurely.

- Designed the **private, mutual-interest matchmaking logic**, including tournament and category compatibility.
- Built separate flows for adult players and **parent/guardian-managed junior profiles**, with additional privacy restrictions for minors.
- Worked on authentication, backend rules, database permissions, tournament discovery and multilingual user experiences.
- Developed automated testing and deployment workflows, alongside an **iOS application undergoing internal TestFlight testing**.

**Stack:** Next.js · React · TypeScript · Supabase · PostgreSQL · Vercel · Vitest · Playwright · Capacitor / iOS

### Final Degree Project — Digital Asset Authenticity

**Academic project · Award-winning**

Designed and developed a web application focused on the management and verification of digital asset authenticity.

- Developed a React frontend with a Node.js / Express backend and MySQL database.
- Explored how software systems can support trustworthy verification processes.
- Awarded **third prize for Best Final Degree Project** by the UIB Cybersecurity Chair.

**Stack:** React · Node.js · Express · MySQL
